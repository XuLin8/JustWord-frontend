# JustWord MVP 第一阶段 · 正式范围定义

> 版本：v1.0　状态：已定稿　更新日期：2026-08-24
> 本文档定义 MVP 第一阶段的**产品范围**，作为后续开发与验收的单一依据。
> 范围约定：**本阶段聚焦前端实现，后端只定义接口契约，具体实现后续补充。**

---

## 1. 产品定位

### 1.1 一句话定位
面向**大学生备考人群**（四六级 / 考研）的智能单词学习应用：内置备考词书，通过「英译汉 → 汉译英」两轮巩固 + 规则化智能批改，帮助用户高效掌握目标词汇，并支持多端云端同步。

### 1.2 目标用户与场景
| 用户画像 | 典型场景 | 核心诉求 |
|---|---|---|
| 四六级备考学生 | 考前 3-6 个月背大纲词 | 有词书可背、掌握度可视化、碎片时间复习 |
| 考研备考学生 | 每天固定时段集中学习 | 高频词优先、错词反复巩固、多端进度一致 |

### 1.3 核心价值主张
- **开箱即背**：内置四六级 / 考研大纲词书，无需自建词库即可开始
- **科学巩固**：两轮学习（英译汉 + 汉译英）+ 规则化批改（完全/部分/近义/拼写）
- **进度可追踪**：掌握度分层、学习报告、打卡成就
- **多端一致**：注册登录后词库 + 学习记录云端同步

### 1.4 非目标（Non-goals）
- 不引入 AI 大模型批改（纯规则判断）
- 不做公网部署（本地验收即可，部署文档另行预留）
- 不做原生 App（本期交付 Web + PWA 可安装形态）
- 不做社交 / 社区 / 排行榜

## 3. 核心用户旅程（MVP 主线）

```
注册/登录 ──▶ 选择内置词书（四六级/考研）──▶ 订阅词书到学习计划
     │                    │
     │                    ▼
     │              英译汉学习（第一轮）
     │                    │
     │              汉译英巩固（第二轮）
     │                    ▼
     │              结果报告（掌握度/答题构成/逐题回顾）
     │                    ▼
     └───────────▶ 仪表盘（进度/打卡/成就/趋势）──▶ 云端同步（词库+学习记录）
```

## 5. 验收标准（Definition of Done）

> 每项 P0 功能须同时满足：功能可用 + 明/暗双态通过 + 中英 i18n 通过 + 无 TS/构建错误 + 分模块提交。

### 5.1 用户系统
- [ ] 可注册新账号、登录、退出；登录态刷新后保持（token 持久化）
- [ ] 未登录访问受保护页面时引导登录
- [ ] 错误场景（账号重复 / 密码错误）有明确 i18n 提示

### 5.2 内置词书
- [ ] 词书列表展示名称 / 词数 / 级别，支持选择
- [ ] 词书词条可分页拉取，订阅后可进入学习
- [ ] 四六级 / 考研各至少一本词书可用（数据源就绪）

### 5.3 词库管理（回归）
- [ ] 添加 / 编辑 / 删除 / 去重 / 搜索 / 导入导出全部可用
- [ ] 词库与词书订阅数据不冲突

### 5.4 学习模式（回归）
- [ ] 两轮学习完整走通，规则批改（完全/部分/近义/拼写）判定正确
- [ ] 结果报告展示掌握度分层、答题构成、逐题回顾

### 5.5 云端同步
- [ ] 词库 + 学习记录可上传 / 下拉，增量基于 `lastSyncAt` 或全量校验
- [ ] 换设备登录后数据可恢复
- [ ] 离线可学习，联网后自动同步（本地优先冲突策略）

### 5.6 PWA
- [ ] 桌面 / 手机可安装，具备独立图标与应用名
- [ ] 核心页面离线可访问（Service Worker 缓存策略）
- [ ] 加载性能达标（首屏可交互时间合理，构建体积可接受）

### 5.7 通用（非功能）
- [ ] 明 / 暗主题双态全部通过
- [ ] 中 / 英 i18n 全覆盖，无硬编码中文
- [ ] 响应式：桌面 / 移动端（≥420px）布局正确
- [ ] `tsc -b` 与 `vite build` 零错误

## 6. 后端接口契约（前端关注 · 接口先行）

> 仅定义接口，**后端实现后续补充**。已有对接接口标注「已有」，其余为新增契约。
> 统一前缀 `/api`，鉴权用 `Authorization: Bearer <token>`。

### 6.1 auth（已有）
| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/auth/register` | POST | `{ username, email, password } → { token, user }` |
| `/api/auth/login` | POST | `{ account, password } → { token, user }` |
| `/api/auth/me` | GET | 当前用户信息 |

### 6.2 words（已有）
| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/words` | GET / POST | 列表 / 新增 |
| `/api/words/{id}` | PUT / DELETE | 更新 / 删除 |

### 6.3 textbooks（新增契约 · 内置词书）
| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/textbooks` | GET | 词书列表 `[{ id, name, level, wordCount, description }]` |
| `/api/textbooks/{id}/words` | GET | 词条分页 `?page=&size=&keyword=` |
| `/api/textbooks/{id}/enroll` | POST | 订阅词书到个人学习计划 |

### 6.4 sync（新增契约 · 词库 + 学习记录）
| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/sync/words` | PUT | 客户端词库全量/增量推送（含 `lastSyncAt`） |
| `/api/sync/words` | GET | 增量拉取 `?lastSyncAt=` |
| `/api/sync/records` | PUT | 学习记录批量上报 |
| `/api/sync/records` | GET | 学习记录拉取 `?lastSyncAt=` |

### 6.5 stats / 打卡 / 成就（已有，复用）
| 接口 | 方法 | 说明 |
|---|---|---|
| `/api/dashboard/stats` | GET | 仪表盘统计（复用现状） |
| `/api/checkin` | POST | 每日打卡（复用现状） |
| `/api/achievements` | GET | 成就列表（复用现状） |

## 7. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 内置词书（数千词条）分页加载流畅；学习/列表操作无感知延迟 |
| 离线 | 词书与词库本地缓存（IndexedDB/localforage），离线可学习、联网自动同步 |
| 主题 | 明 / 暗双态，遵循语义 token（variables.css + globals.css） |
| i18n | 中 / 英，全部走 `t()`/i18n，不新增硬编码中文 |
| 响应式 | 移动端优先适配（PWA 场景），≥420px 断点正确 |
| 安全 | 密码不明文存储；token 持久化；接口鉴权 |
| 工程质量 | 分层目录规范、`@/` 别名、命名导出、模块一致提交、无 `any` 网络裸数据 |
