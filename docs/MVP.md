# JustWord MVP 第一阶段 · 正式范围定义

> 版本：v1.0　状态：已定稿　更新日期：2026-08-24
> 本文档定义 MVP 第一阶段的**产品范围**，作为后续开发与验收的单一依据。
> 范围约定：**本阶段聚焦前端实现，后端只定义接口契约，具体实现后续补充。**

## 1. 产品定位

### 1.1 一句话定位
面向**大学生备考人群**（四六级 / 考研）的智能单词学习应用：内置备考词书，通过「英译汉 → 汉译英」两轮巩固 + 规则化智能批改，帮助用户高效掌握目标词汇，并支持多端云端同步。

### 1.2 目标用户与场景
| 用户画像 | 典型场景 | 核心诉求 |
|---|---|---|
| 四六级备考学生 | 考前 3-6 个月背大纲词 | 有词书可背、掌握度可视化、碎片时间复习 |
| 考研备考学生 | 每天固定时段集中学习 | 高频词优先、错词反复巩固、多端进度一致 |

### 1.3 核心价值主张
- **开箱即背**：内置四六级 / 考研大纲词书，无需自建词库即可开始
- **科学巩固**：两轮学习（英译汉 + 汉译英）+ 规则化批改（完全/部分/近义/拼写）
- **进度可追踪**：掌握度分层、学习报告、打卡成就
- **多端一致**：注册登录后词库 + 学习记录云端同步

### 1.4 非目标（Non-goals）
- 不引入 AI 大模型批改（纯规则判断）
- 不做公网部署（本地验收即可，部署文档另行预留）
- 不做原生 App（本期交付 Web + PWA 可安装形态）
- 不做社交 / 社区 / 排行榜

### 4.3 核心单词记忆界面（学习首页）设计要点

**定位**：登录后首页 = 背单词主战场，**沉浸式全屏**，视觉风格接近 **LeetCode UI**（克制、面板化、明暗双态）。

**布局结构（从上到下）**
1. **顶部 · 全局字典搜索条**：常驻顶部，支持单词搜索（查词 / 直达），搜索框 + 可快捷键唤起（`/` 或 `Ctrl+K`）
2. **中部 · 背单词主区（屏占比最大）**：
   - 渐变轻松的背景颜色（主题感知，明 / 暗双态，遵循语义 token）
   - 当前单词**醒目**展示（大字号 / 大字重）
   - 学习流程：**先只给单词** → 用户「认识 / 不认识」IO 判定 → 展开详情
   - 展开详情：发音（TTS 播放）+ 音标、释义、例句、形近词、近义词、反义词
3. **控制区**：上一词 / 下一词切换，支持**三通道交互**：
   - 鼠标手势（拖拽 / 滑动）
   - 按钮（上 / 下切换）
   - 键盘输入（`↑` / `↓` / `空格` 快捷键）

**背诵规则（用户自选）**
| 规则 | 流程 | 判定 |
|---|---|---|
| 听词默写 | 播放发音 → 用户默写输入 | 规则化（拼写比对） |
| 看词选意 | 展示单词 → 选择含义 | 规则化（选项比对） |
| 两轮学习（兼容现有） | 英译汉 → 汉译英 | 规则化（现状复用） |
| 表格背诵（Excel 背诵法） | 表格：英文列→填中文；再隐藏英文列→据中文列写英文 | 规则化（逐格比对） |

**表格背诵（Excel 背诵法）设计**
- 网格表格样式：一列英文单词 + 相邻列填中文意思（Excel 式单元格，焦点可跳格）
- 两阶段：**正向填意**（给英文列填中文）→ **反向遮罩写词**（隐藏英文列，据中文列写出英文）
- 可混入**复习队列**：昨日 / 最近学习的若干单词一并入表，边学边复习
- 判定逐格比对，错词标记后进入错词复习

**学习配置与闭环**
- 用户自定义**当日记忆单词数量**（今日目标）
- 进度展示（今日完成 / 目标）
- 目标达成 → **打卡**（复用 checkin 接口）

**归属**：结构在 **M2** 落地（依赖词书 / 学习计划），交互与视觉打磨在 **M4**。

**技术依赖 / 开放问题**
- TTS 发音：Web Speech API（免费）vs 外部音源（选型待定）
- 听词默写判定：本地规则（MVP 可行）
- 形近词 / 反义词数据来源：需数据或规则生成（近义词可复用 `learn.similar` 域）

### 4.4 云养猫激励系统（背单词动力）

**定位**：以「云养猫」作为背单词的激励闭环——背单词得货币 / 奖励 → 喂养与丰荣猫咪；猫咪为 **AI 搭配形象** + 待机动画，常驻首页，可互动。

**核心闭环（精简版 · 已定入 MVP）**
- 开局领养 1 只猫（AI 形象，默认装扮）
- 背单词 / 打卡 → 获得**货币 / 奖励**
- 货币用于**丰荣**：喂食、玩耍、装饰
- 猫咪基础状态：饱食 / 心情（喂养与互动提升）
- 首页猫咪 UI + 待机动画 + 基础互动（点击 / 抚摸反馈）

**首页与看板形态（已定）**
- **学习为主，猫咪陪伴**：核心单词记忆界面常驻猫咪角落（待机动画 + 可互动）
- 可选择**猫咪作为看板**（猫咪页为主界面）
- **单独的猫咪页**：独立入口，展示猫咪 + 互动
- **学习判定音效联动**：点「认识」→ 轻松甜美的喵声特效；点「不认识 / 不熟悉」→ 生气的哈气音

**扩展规则（可再议 · M5+）**
- **负面情绪**：饥饿 / 不满累积 → 猫咪**离家出走**（需找回机制）
- **随机属性**：品种 / 性格 / 体重 / 身高 / 胃口 / 叫声（开局随机）
- **装扮系统**：稀有装扮（外观 + 特效）
- **猫窝区域**：喂食喂水、铲猫砂、置办玩具与装饰品——与竞品形成**最大差异化**
- 成就联动：学习里程碑解锁猫的装扮 / 场景

**付费点**：**暂不记录（搁置）**，后续再议。

**规则待议清单（Open）**
- 猫的数值模型（饱食 / 心情 / 离家出走阈值）
- 货币产出与消费平衡
- 离家出走触发与找回规则
- 装扮 / gacha 概率与稀有度
- AI 形象生成方案（预置资产 vs 动态生成）
- 待机动画实现（Lottie / CSS / 序列帧）

**归属（已定）**：**精简核心闭环入 MVP**（首页陪伴 + 学习得币 + 互动音效 + 猫咪看板页）；完整系统（随机属性 / 离家出走 / 装扮 gacha / 猫窝区域）作为 **M5+ 后续阶段**。
